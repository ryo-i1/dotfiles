# App Cheat Sheets

dotfiles で設定を管理していない app の cheatsheet を置きます．
設定ファイルや install script は持たず，操作方法と keybind の確認を
目的にします．

## Files

新しい app は，`docs/apps/<app-name>.md` として追加します．
file name は小文字の kebab-case にします．
たとえば，`raycast.md` や `visual-studio-code.md` のようにします．

## Template

新しい cheatsheet は，まず [Template](TEMPLATE.md) をコピーして
必要な項目だけを残します．
頻繁に使う操作を上に置き，公式 shortcut の全列挙にはしません．

## Index

まだ app cheatsheet はありません．
